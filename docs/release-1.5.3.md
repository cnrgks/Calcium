# Calcium 1.5.3

- Panel scrollbars no longer paint over overlapping suggestions and menus; single-line inputs do not receive horizontal overlay scrollbars.
- Send selected tabs to the vault together, saving the entire batch before closing source tabs.
- Put all selected tabs to sleep, including the active tab, while keeping an awake tab available. Multi-tab menu actions now use plural labels.
- Keep-awake actions in the tab menu affect only selected tabs, including when other tabs share the same site. Enabling keep-awake wakes selected sleeping tabs without changing the active tab.
- Preserve tab-specific keep-awake preferences in restored sessions.
