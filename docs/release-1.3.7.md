Calcium 1.3.7 keeps the interface small while adding more control over everyday browsing.

- Add your own `!` commands for site search and navigation, and `#` text replacements in Settings. YouTube and Wikipedia examples are available to fill in; nothing is added until you save it.
- Address suggestions use only your previous searches. No visited URLs, bookmarks or remote suggestions.
- Ctrl+scroll changes page zoom. The percentage beside the address bar resets zoom to 100% when clicked.
- Site controls open below the lock icon, with switches for keeping tabs awake and protecting cookies. Related sign-in sites can be protected from the same popup. Awake tabs have a coffee badge.
- Fixed vertical-tab drag clipping and added matching thin overlay scrollbars to scrollable panels and embedded documents.
- Private windows can reopen their own closed tabs with Ctrl+Shift+T. Closing the window discards that list.
- About Calcium now includes on-demand update checks. The small startup offer appears at the top right; Later stops further offers. Downloads start only after choosing Update. macOS uses manual installation from the release page.
- Added keyboard shortcuts to Settings, bone theme previews, translation fixes and protection against closed-output-pipe crashes.
- Improved private-window filtering and keyboard focus handling; added repeatable security, integration and soak checks.

Downloads: Windows x64 installer, Intel macOS DMG and Apple Silicon macOS DMG. SHA-256 checksums are included.

Packages are unsigned, and macOS builds are not notarized. DRM playback still depends on unavailable castLabs VMP signing. Bitwarden 2026.10.2 passed a basic load/sign-in-screen smoke test; unlocked-vault autofill and native/biometric integration were not tested. See [validation details](https://github.com/cnrgks/Calcium/blob/main/docs/release-validation.md).
