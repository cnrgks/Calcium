This update fixes theme switching and improves the macOS layout.

- Pitch black now switches on and off immediately, including the Settings page.
- Horizontal active tabs use the toolbar background for a consistent joined surface.
- Vertical tabs and first-run setup reserve space for the macOS window buttons.
- The macOS Dock icon has a transparent margin so it matches neighboring icons more closely.
- Removed the keyboard-shortcut reference section from Settings. Custom site commands and text replacements remain available.
- Startup and setup completion no longer automatically focus or open the address input. Explicit actions such as Ctrl+T and clicking the address bar still work.

Windows 1.3.7 users can check and install this update from Settings → About Calcium. Choosing Later previously suppresses automatic offers, but manual checks still work. Windows versions without the updater need the installer from this release. macOS updates are installed manually using the matching Intel or Apple Silicon DMG.

Windows x64, Intel macOS and Apple Silicon macOS packages are included, with SHA-256 checksums. Packages remain unsigned; macOS builds are not notarized. No change to DRM signing availability.
