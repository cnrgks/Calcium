- Added optional built-in Tab Vault (Sekme Kasası), off by default in Settings → Tools. Select tabs from the toolbar popup, save and close them, then manage groups at `calcium://saved-tabs`.
- Reorder and merge groups, move tabs between groups, drag a tab into the new-group target, rename groups inline and select multiple tabs with Ctrl/Shift.
- Restore individual tabs or selections, recover opened tabs from Trash, and paste or copy plain-text tab lists in the import/export dialog.
- Send tabs to the vault from the tab or page context menu. Consecutive sends join the same group until 60 seconds have passed since the last send.
- Added a preloaded popup with fixed footer controls, remembered preferences and live archive updates. Settings changes preserve scrolling and expanded sections.
- Added archive persistence, import/export, drag-and-drop, selection, context-menu and popup regression tests to the release checks.
