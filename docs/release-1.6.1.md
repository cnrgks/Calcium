# Calcium 1.6.1

- Improve volume boosting for delayed media, embedded players and open shadow roots; preserve zero-volume settings and avoid repeated player connections.
- Improve image hover previews for layered images, CSS backgrounds, responsive and lazy-loaded sources, GIFs and muted looping video previews.
- Reduce repeated media scans and align preview movement with screen refreshes.
- Add a compact, theme-aware new-tab notification with animated dismissal when the tab drawer opens.
- Display multiple selected tabs with outlines instead of selection fills.
- Make Calcium protection a global Settings switch and remove per-site context-menu controls and legacy exceptions.
- Add regression checks for media discovery, frame installation and notification layering.

Compatibility: some cross-origin audio sources, site-owned Web Audio graphs, closed shadow roots and canvas-rendered media remain unsupported. Automated checks do not guarantee compatibility with every website.
